## 🚀 About

A premium, dark-themed portfolio website designed to feel like a high-end SaaS product page — not a generic student resume. Features immersive particle animations, 3D tilt effects, scroll-triggered reveals, and a custom cursor experience.

**Built for:** Pranav Rowthri — Web Developer | React & Frontend Specialist

## ⚡ Animation Libraries (CDN — zero install)

| Library | Version | Purpose |
|---------|---------|---------|
| [GSAP](https://greensock.com/gsap/) + ScrollTrigger | 3.12.5 | Hero entrance timeline, skill bar fills, cursor lag, parallax blobs |
| [AOS](https://michalsnik.github.io/aos/) | 2.3.4 | Scroll-triggered fade/slide reveals on sections & cards |
| [Typed.js](https://mattboldt.com/demos/typed-js/) | 2.0.16 | Typewriter cycling text in hero |
| [Particles.js](https://vincentgarreau.com/particles.js/) | 2.0.0 | Neural network particle background with mouse interaction |
| [Vanilla Tilt.js](https://micku7zu.github.io/vanilla-tilt.js/) | 1.8.1 | 3D tilt + glare on project cards |
| [ScrollReveal](https://scrollrevealjs.org/) | 4.0.9 | Timeline & certification card staggered reveals |

## 📂 Sections

- **🏠 Hero** — Full-viewport particle canvas, letter-by-letter name reveal, cycling role text
- **👤 About** — Two-column layout with bio & animated skill tags
- **🛠️ Skills** — 9 skill cards with animated progress bars (GSAP ScrollTrigger)
- **💼 Projects** — Glassmorphism cards with 3D tilt hover effect
- **🎓 Education** — Alternating timeline with pulsing dots
- **📜 Certifications** — 6 credential cards (NxtWave, Udemy, LinkedIn Learning, Cisco)
- **📬 Contact** — Floating-label form, social links, glowing inputs
- **🖱️ Custom Cursor** — Glowing dot + expanding ring on interactive elements (desktop)

---

## 🏗️ Tech Stack

```
HTML5 + CSS3 + Vanilla JavaScript
├── No frameworks, no build tools, no dependencies to install
├── Single index.html file (~1900 lines)
├── All animation libraries loaded via CDN <script> tags
├── Google Fonts via <link> in <head>
└── prefers-reduced-motion respected throughout
```

## 🖥️ Getting Started

**Clone & open — that's it:**

```bash

cd Portfolio
open index.html    # macOS
# or just double-click index.html in your file manager
```

No `npm install`. No build step. No server required.

## ♿ Accessibility

- Semantic HTML5 elements (`<nav>`, `<section>`, `<footer>`)
- ARIA labels on interactive elements
- `prefers-reduced-motion` media query disables all animations
- Keyboard-navigable links and form inputs
- Proper heading hierarchy (single `<h1>`)
